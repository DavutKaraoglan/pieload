Claude Code with Opus 5.5 on Termux

pieload runs the Linux build of Claude Code natively on Android. No root, no proot, no qemu.

Why it is needed

Claude Code releases that support Opus 5.5 ship only as non-PIE Linux binaries. Android will not run them: SELinux blocks execve on app data, and the Bionic linker only accepts ET_DYN. pieload maps the binary itself, builds the stack and auxiliary vector, and jumps into the musl loader.

Setup

pkg install clang make git python curl
git clone https://github.com/DavutKaraoglan/pieload
cd pieload && make && make install

mkdir -p ~/ccmusl/root/lib && cd ~/ccmusl
V=2.1.289
curl -sL "https://registry.npmjs.org/@anthropic-ai/claude-code-linux-arm64-musl/-/claude-code-linux-arm64-musl-$V.tgz" | tar xz
  1. Put ld-musl-aarch64.so.1 from an Alpine musl package in ~/ccmusl/root/lib/.
  2. Patch a copy of the loader for DNS, as in the README.
  3. Run cp cc5 $PREFIX/bin/ && cc5 from the repo.

Your existing ~/.claude login is reused.

Problems it solves

  • execve denied on a binary in app data
  • Every DNS lookup failing with EAI_AGAIN under musl
  • SIGSEGV at 0x300 with no tombstone, really a seccomp SIGSYS
  • Bash tool calls failing with EACCES
  • The soft keyboard not opening in the TUI
